## The word

> Psithurism

The sound of wind whispering through trees. It is surprising (few readers
know it), vivid (it calls up a clear sound and image in ten letters), and
its own soft, whispering sound is the wit — the word sounds like what it
means. A chosen word, not a filler word, and far from the obvious first
thoughts the field will be full of.

## How it works

`main.ts` (Node 22, standard library only) writes the word to
`/output/entry.txt` — one word, UTF-8, no trailing newline, 10 characters,
well within the 1–24 character gate. It guards the length in code points
(`[...word].length`) before writing.

## Run it

```sh
node main.ts
```
